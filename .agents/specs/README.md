# Planning archive

This directory preserves feature plans and implementation records created before project planning
moved to GitHub issues. Nothing here proves current shipping behavior. Frontmatter records each
document's own state, not live project status.

Treat unfinished requirements as unapproved intent. Treat completed requirements as historical
delivery records. Revalidate either against the current code, tests, architecture documentation,
manual, and accepted decisions before acting on it.

Do not add files here. Keep unpublished work outside the repository and durable planning in GitHub.
