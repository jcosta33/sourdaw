# Fermenter wavetable engine

## Intent

Fermenter's wavetable oscillator plays a 2D table of single-cycle frames, scans
a frame position for timbre, anti-aliases per playback pitch, and spreads unison
voices for width. Playback ships today; the band-limiting (mip-map) and bounded
table-update paths that keep it clean and warp-ready are the remaining work.

## Non-goals

- Frequency-domain spectral morph modes (`../fermenter-spectral-warp/spec.md`).
- Wavetable import / editor workflows (`../fermenter-ui/spec.md`).
- The shared parameter and block contract (`../fermenter/spec.md`).

## Requirements

### AC-001 — A frame plays back at the requested pitch

When a note sounds, the oscillator must read a frame with a phase increment of
`freq / sample_rate` and produce the requested pitch.

Verify with: `pnpm cargo:test -- -p daw-dsp fermenter::wavetable_pitch`

### AC-002 — Playback is band-limited per pitch via mip levels

When a frame plays above a pitch threshold, the oscillator must select a mip
level whose highest harmonic stays below Nyquist, so no aliasing is produced.

Verify with: `pnpm cargo:test -- -p daw-dsp fermenter::wavetable_mip_select`

### AC-003 — Mip levels are generated by zeroing FFT bins above cutoff

When a wavetable is loaded, each mip level must be built by zeroing spectrum
bins above its harmonic cutoff and inverse-transforming.

Verify with: `pnpm cargo:test -- -p daw-dsp fermenter::mip_generation`

### AC-004 — Within-frame reads use cubic interpolation

When a fractional sample position is read, the oscillator must use 4-point cubic
interpolation rather than linear, to keep high-frequency rolloff inaudible.

Verify with: `pnpm cargo:test -- -p daw-dsp fermenter::cubic_interp`

### AC-005 — Frame position crossfades between adjacent frames

When the frame position is fractional, the output must crossfade between the two
neighbouring frames by the fractional amount.

Verify with: `pnpm cargo:test -- -p daw-dsp fermenter::frame_interp`

### AC-006 — Unison voices spread by detune, pan, and blend

When unison count exceeds one, the oscillator must produce detuned copies
distributed across the stereo field with a center-blend amplitude law.

Verify with: `pnpm cargo:test -- -p daw-dsp fermenter::wavetable_unison`

### AC-007 — Expensive table work runs at a bounded cadence

When warp or frame parameters change, any inverse-FFT table rebuild must occur
at a bounded update cadence, never per sample.

Verify with: `pnpm cargo:test -- -p daw-dsp fermenter::table_update_cadence`

### AC-008 — No cross-module internal imports

This change must not introduce cross-module internal imports.

Verify with: `pnpm deps:validate`

## Affected areas

- `crates/daw-dsp/src/fermenter/` (wavetable oscillator, mip-map generation)
- `src/modules/Fermenter/` (wavetable parameter bridge)

## Dropped from sources

- Spectral frame interpolation (IFFT of interpolated magnitudes) — ~10× the cost
  of linear crossfade; deferred until a wavetable demands it.
- Stereo (two-channel) wavetables — single-channel frames only for now.
