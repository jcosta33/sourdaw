Plugin interface notices
========================

Sourdaw hosts third-party audio plugins by declaring the plugin formats' own
interfaces. It bundles no plugin-format SDK, links no Steinberg or CLAP binary,
and redistributes no plugin.

Two Rust crates carry those interface declarations into Sourdaw:

  * `vst3` 0.3.0 (with `com-scrape-types` 0.1.1), which reproduces the VST 3
    interface declarations.
  * `clap-sys` 0.5.0, which reproduces the CLAP interface declarations.

Both crates are published under MIT OR Apache-2.0 and ship the license texts of
their own authors. Neither ships the interface authors' notice, so the notices
those interfaces require are reproduced here.
