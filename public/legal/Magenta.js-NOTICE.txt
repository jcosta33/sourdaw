Magenta.js DDSP code notice

Sourdaw includes code adapted from the Magenta.js DDSP implementation at this
immutable upstream revision:

https://github.com/magenta/magenta-js/tree/0692eb2b79681f062c6b6dd53a0361967f298caa

The adapted code basis is limited to these exact upstream source files:

- music/src/ddsp/ddsp.ts
  Feature conditioning, frame conversion, and chunk padding.
- music/src/ddsp/model.ts
  DDSP chunk scheduling, one-second overlap, post-gain, and GraphModel Roll
  operation registration adapted by Sourdaw's tfjsInferenceWorker.ts.
- music/src/ddsp/constants.ts
  Conditioning and one-second crossfade constants.
- music/src/ddsp/audio_utils.ts
  Linear overlap/crossfade behavior.
