# Setlist module — Agent Guidelines

Owns live performance setlists, song sequence items, per-song metadata (tempo/key/duration), count-in configurations, and auto-advance playback progression; does not own project serialization (Project) or audio engine playback (AudioEngine / Transport).

## Public Contract Surface

Public surface: `useCases/index.ts`, `stores/index.ts`, `presentations/views/index.ts`.

## Key Subsystems

- **Setlist Aggregate:** `setlistStore` maintains the ordered list of performance songs, active item pointer, elapsed time, and auto-advance configuration.
- **Progression Controller:** Logic for stepped song navigation (`nextItem`, `previousItem`, `goToItem`) and automatic timer-based progression.
- **Stage HUD:** `SetlistPanel` provides the live performance interface displaying song metadata, countdown clocks, and next-up previews.

## Invariants & Traps

- **Index Bounds Integrity:** Active item index must strictly clamp to `[-1, items.length - 1]`.
- **Stable Item Identification:** Song item IDs generated by `repositories/setlistItemIdCounter.ts` must remain persistent across reorders and edits.
- **Non-Blocking Transitions:** Auto-advance song transitions must execute asynchronously without stalling UI interaction or audio playback.
